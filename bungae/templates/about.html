이용 안내

번개팟구는 숭실대학교 AI개발과실전 수업의 팀 프로젝트로 만든 서비스예요.

어떤 서비스인가요

갑자기 시간이 비었을 때 같이 밥을 먹거나 공부하거나 놀 사람을 교내에서 찾는 번개 모임 서비스예요. 번개를 직접 열 수도 있고, 열려 있는 번개에 참여할 수도 있어요.

저장하는 정보

  • 가입할 때 입력한 학교 이메일, 닉네임, 관심사. 비밀번호는 원문이 아니라 되돌릴 수 없는 형태(해시)로만 저장해요.
  • 내가 연 번개, 참여 기록, 댓글, 받은 알림, 내가 한 신고(사유만).
  • 로그인에 연달아 실패한 횟수(잠금을 위한 것이고, 로그인에 성공하면 지워요).
    • {% if config.EMAIL_VERIFICATION %}
  • 메일로 보낸 인증·재설정 코드의 발송 기록(코드 숫자는 저장하지 않고, 하루가 지나면 지워요).
    • {% endif %}
  • 추천 챗봇을 하루에 몇 번 썼는지(횟수만). 대화 내용은 저장하지 않아요.

다른 학생에게 보이는 것은 닉네임, 내가 쓴 모임 글과 댓글, 내가 참여한 번개의 참여자 목록에 오른 닉네임, 그리고 호스트일 때 지금까지 번개를 열고 참여한 횟수예요. 이메일과 누가 신고했는지는 다른 사람에게 보이지 않아요. 오픈채팅 링크는 그 번개에 참여한 사람에게만 보여요.

이용 규칙

  • 번개는 오늘부터 14일 안의 일정만 열 수 있고, 한 사람이 동시에 열어 둘 수 있는 번개는 5개까지예요.
  • 참여는 선착순이고 정원이 차면 자동으로 마감돼요. 시작 시간이 지나면 참여도 취소도 할 수 없어요.
  • 오픈채팅 링크는 카카오 오픈채팅 주소(https://open.kakao.com/)만 넣을 수 있어요.
  • 서로 다른 3명이 신고한 번개는 모집이 자동으로 멈추고 다시 열 수 없어요. 가입한 지 하루가 안 된 계정의 신고는 그 번개의 참여자일 때만 세요.
    • {% if config.EMAIL_VERIFICATION %}
  • 가입할 때 학교 메일로 보낸 코드를 입력해야 계정이 만들어져요. 비밀번호를 잊으면 같은 메일로 코드를 받아 다시 정할 수 있어요.
    • {% else %}
  • 비밀번호를 잊었을 때 다시 설정하는 기능은 아직 없어요.
    • {% endif %}

추천 챗봇과 AI

챗봇에 보낸 문장은 시간과 활동 종류를 알아내기 위해 외부 AI 서비스(OpenRouter의 무료 모델)로 전달될 수 있어요. 이때 전달되는 것은 입력한 문장, 현재 시각, 앞선 대화에서 알아낸 조건(날짜·시간·활동 종류)뿐이고, 이름·이메일이나 다른 사람의 모임 글은 전달되지 않아요. 그래도 챗봇에는 개인정보를 적지 말아 주세요.

안전하게 만나기

    {% if config.EMAIL_VERIFICATION %}
  • 학교 메일을 받을 수 있는지는 확인하지만, 상대가 지금 재학 중인지까지는 보장하지 못해요.
    • {% else %}
  • 학교 이메일 형식만 확인하고 있어서 상대가 실제 재학생인지는 보장하지 못해요.
    • {% endif %}
  • 처음 만나는 사람과는 학생회관, 도서관처럼 사람이 많은 교내 장소에서 만나세요.
  • 돈을 먼저 보내 달라거나 개인정보를 요구하는 모임에는 참여하지 마세요.

탈퇴와 정보 삭제
